# 数据分析报告（真实统计）

> 本报告所有数字均来自对原始数据集的脚本统计（非估算），用于支撑 README 中的数据情况与方法设计。

## 1. 数据集规模
| 集合 | 图片数 | 正样本(有框) | 负样本(空标签) | 标注框数 |
|------|-------|------|------|------|
| 训练集(清洗后) | 10960 | 5267 | 5692 | 5533 |
| 验证集 | 2739 | 1239 | 1500 | 1297 |
| A榜测试集 | 2049 | 未知 | 未知 | — |
| B榜测试集 | 4443 | 未知 | 未知 | — |
| 人工核查子集 | 1955 | 1041 | 914 | 1386 |

> 负样本占比约 50%，类别极不平衡，需正负样本均衡策略（保留空标签作为负样本训练）。

## 2. 图像尺寸分布（训练集，n=2500 抽样）
- 宽度：min 63, p50 **294**, p90 543, max 1080
- 高度：min 134, p50 **613**, p90 775, max 1643
- 尺寸跨度极大，非固定分辨率 → 训练用 `rect=True` 自适应批次。

## 3. 目标框像素分布（训练集，1274 框抽样）
- 目标框占图面积比例：min 0.4%, p50 **2.24%**, p90 16.9%, max 100%
- 面积分级：small(<1%) **8.2%** / medium(1%~10%) **78.2%** / large(>10%) **13.6%**
- 宽高比：min 0.19, p50 0.88, max 3.67（近竖向持机为主）

**结论**：小目标比例不高（<1% 仅 8.2%），但尺寸跨度大 → 采用 1280 高分辨率输入提定位，而非专门小目标增强。

## 4. B榜分布偏移（n=1500 抽样）
- B榜图片尺寸：中位 309×640，p90 640×775，max 1080×1439
- **极端宽高比（>1.8）图占比 54.0%**（黑边 / letterbox / 宣传海报）
- 这是 B榜特有分布偏移，训练集几乎无此类样本 → 黑边误检是头号杀手。

## 5. 人工核查弱项量化（1955 张，实测量化）
- 预测框总数：1555，误检框(FP)：288，**框级误检率 18.5%**
- 含误检框的图：257 张
- 漏标画框：119 个，含漏检的图：62 张
- 空预测图：885，有预测图：1070
- 空预测图完全漏检：仅 17 张（1.9%）→ 负样本幻觉被高估
- 多手机漏检：45 张（4.2%，展览柜/宣传画并排手机）

**错误类型分布**：完全漏检图 17 / 多手机漏检图 45 / 误检图 257
**FP conf 分布**：0.25-0.30:66, 0.30-0.35:60, 0.35-0.45:67, 0.45-0.60:67, 0.60+:28
→ FP 各区间均匀，提阈值仅砍部分 FP，高 conf 仍有 162 个 FP（相似物混淆）。
